# climat.today

The public site for Climat: product pages, methodology and registry references,
guides and a glossary for carbon project developers.

It is a static site. A single script with no dependencies turns the files in
`content/` into the finished site in `public/`. Any static host can serve `public/`
as it is; nothing has to run on the server.

## Build

    node build.mjs                                    # writes public/
    DRAFT=1 node build.mjs                            # a link to a page not yet written warns instead of failing
    SITE_URL=https://staging.example node build.mjs   # build for another address

Requires Node 18 or later. The build **fails** on invalid front matter, a missing
`title`, `description` or `updated`, or an internal link or anchor that does not
resolve. A page that ships is a page that parsed and whose links work.

To look at the result locally:

    python3 -m http.server 4173 --directory public

## Layout

| Path | What it is |
|---|---|
| `content/` | One file per page. The path is the URL. Format and rules: [CONTENT_GUIDE.md](CONTENT_GUIDE.md) |
| `content/glossary/terms.json` | The glossary, as data |
| `site.config.json` | Name, address, navigation, footer, redirects, crawler list, IndexNow key |
| `src/styles/site.css` | The whole design system, one file |
| `src/brand/` | The logo as supplied. Do not edit: derive from it |
| `src/assets/` | Generated by `tools/make_assets.py` from the logo and the fonts |
| `build.mjs` | The generator |
| `tools/` | `make_assets.py` (fonts, logo variants, icons, social image), `indexnow.mjs` |
| `public/` | The built site. Committed, so a host needs no build step |
| `legacy/` | The previous site, kept intact for reference. Not deployed |

## What the build writes for search engines and answer engines

- Every page as server-rendered HTML with no JavaScript, so crawlers that do not run
  scripts read everything.
- Title, description, canonical address, Open Graph and Twitter tags on every page.
- Structured data as one JSON-LD graph per page: Organization, WebSite, WebPage,
  BreadcrumbList, Article with its list of cited sources, SoftwareApplication on the
  product page, DefinedTermSet on the glossary. It is placed at the end of the page so
  the answer sits in the first few thousand characters.
- `sitemap.xml`, with the date of each page's last substantive edit.
- `robots.txt`, which names the AI search, assistant and training crawlers it
  welcomes. Edit the list in `site.config.json`.
- `llms.txt` and `llms-full.txt`, and a Markdown version of every page at the same
  address plus `index.md`.
- `_headers` and `_redirects` for hosts that read them (Cloudflare Pages, Netlify):
  security headers, long caching for hashed files, `noindex` on the Markdown twins,
  and permanent redirects from the previous site's addresses.
- `<key>.txt` for IndexNow.

## Deploying

Serve `public/`. On a host that builds for you, the build command is
`node build.mjs` and the output directory is `public`.

After the first deploy, and once only:

1. Verify the site in Google Search Console and submit `sitemap.xml`.
2. Verify the site in Bing Webmaster Tools and submit `sitemap.xml`.
3. If the site is behind Cloudflare, check that its bot settings are not blocking
   the crawlers that `robots.txt` welcomes.

After every deploy that changes content:

    node tools/indexnow.mjs              # every URL in the sitemap
    node tools/indexnow.mjs /guides/x/   # or only what changed

## Regenerating the brand assets

    pip install fonttools brotli pillow      # and: brew install librsvg
    python3 tools/make_assets.py

## Two rules

1. **Nothing is said about the product that the product does not do.** The fact
   sheet in [CONTENT_GUIDE.md](CONTENT_GUIDE.md) lists what may be claimed, checked
   against the application code, and what is still in development. Update the fact
   sheet first, then the pages.
2. **Every rule, number and deadline on an educational page has a primary source.**
   If the registry's own document cannot be linked, the claim is left out.
