# Document drafting

> Climat drafts each section of the registry's project document from the project's own intake and uploaded evidence. Every statement cites its origin: the intake, an excerpt of the evidence, or the methodology. Citations to uploads are checked against the text supplied, conflicts are raised as warnings, and a person finalizes every section.

Updated 2026-09-29. Canonical: https://climat.today/product/document-drafting/

## What does Climat draft?

It drafts the project document the registry requires: the project description under the Verra Verified Carbon Standard, or the project design document under the Gold Standard for the Global Goals. Sections are written in the registry's own order, and the two registries do not ask for the same sections. See [the VCS project description](https://climat.today/registries/verra-vcs/) and [the Gold Standard PDD](https://climat.today/registries/gold-standard/).

## Where does each statement come from?

Every statement in a draft points to one of three places.

| Citation points to | Example | How it is checked |
| --- | --- | --- |
| The intake | Project area, planting density, installed capacity | The value is the one you entered |
| An excerpt of your evidence | A page of a land record, a row of a census | The excerpt named must be one that was supplied, or the citation is flagged |
| The methodology | A condition, an equation, a required parameter | Drawn from the methodology as set up from its published text |

## What happens when the intake and the evidence disagree?

The disagreement is raised as a warning on the section it affects. If the intake says two species were planted and the uploaded census shows three, the draft does not pick one. It tells you, with the figures, so that you can correct whichever is wrong.

## What happens when evidence is missing?

The section says so. An additionality test with no supporting document is marked as needing evidence. The draft does not fill the gap with a plausible figure. The same gaps appear earlier, in the evidence gap report, so that most of them can be closed before drafting starts.

## Who has the last word?

You do. Each section is read, edited and finalized by a person. A finalized section is never regenerated. For background on what each section has to establish, see [what a project design document is](https://climat.today/guides/what-is-a-pdd/).

## Frequently asked questions

### What is a citation checked against?

A citation to an uploaded document names an excerpt of that document. Climat checks that the excerpt named is one that was actually supplied to the draft. If it is not, the citation is marked unverified and the section is flagged for review.

### Can I change a section after it is drafted?

Yes. You can edit the text directly or ask for a rewrite with your own instructions. Once you finalize a section, it is left alone: drafting the rest of the document again will not touch it.

### Does Climat write the numbers in the quantification section?

It sets out the structure the methodology requires and the parameters involved, and it uses the values you supplied. It does not invent a value for a parameter that has no source.
