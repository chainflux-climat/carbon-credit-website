# Methodologies

> A methodology is the rulebook a carbon project is assessed against. For each methodology Climat supports, these pages explain what it covers, which conditions a project must meet, how additionality and the baseline are established, and what has to be monitored. Every page names the version it describes and the date it was checked.

Updated 2026-09-29. Canonical: https://climat.today/methodologies/

## How does Climat add a methodology?

We read the published methodology in full, then write down its applicability conditions, the inputs it requires, its approach to additionality, its baseline, and its monitoring parameters. Anything we could not check against the primary text is marked as unverified and is not offered to customers.

That is why the list is short. A methodology that is nearly right produces a project document that is nearly right, and a validator will find the difference.

## Which methodology should we add next?

The order is set by the people using Climat. If you are working under a methodology that is not listed here, [tell us which one](https://climat.today/contact/) and where your project stands.
